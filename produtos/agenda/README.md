# Desenhe agendamento dentro do WhatsApp

Por Pedro Angarita · FR-GRA-004 · versão 0.1.0 · rascunho · 06/10/2026

Para donos de negócios que querem visualizar como o cliente escolhe um serviço e solicita um horário. Este material é um roteiro de jornada e teste no papel; não é um Flow JSON instalável.

## Monte a jornada

1. Liste serviços, campos mínimos e a fonte real de disponibilidade.
2. Desenhe: serviço → preferência de horário → resumo → solicitação.
3. Defina onde a equipe ou sistema confirma a reserva.
4. Simule horário livre, horário ocupado e indisponibilidade do sistema.

## Exemplo fictício

Uma oficina oferece revisão simples. Ana, pessoa fictícia, escolhe o serviço e solicita terça às 10h. O resumo diz “solicitação recebida”. Só após a confirmação da equipe ou transação no sistema a mensagem diz “agendamento confirmado”. Se duas pessoas pedirem a mesma vaga, a disponibilidade deve ser resolvida no sistema responsável antes da confirmação.

## O que conferir

Campos necessários claros; opção de corrigir; ausência de promessa antes da reserva; falha encaminhada a uma pessoa; nenhum dado real usado no exercício.

## Limites

Construir e publicar em WhatsApp Flows exige conta elegível, configuração, integração e teste específicos. Preço e regras precisam ser verificados no momento da implementação. Este kit não inclui infraestrutura nem acesso à conta.
