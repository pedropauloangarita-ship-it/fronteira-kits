# Kits de IA aplicada

Materiais gratuitos em português para aprender com tarefas pequenas. Por Pedro Angarita. Versão inicial educacional: quatro kits em rascunho para teste e duas pautas planejadas.

## Catálogo

| SKU | Produto | Palavra | Estado |
|---|---|---|---|
| FR-GRA-001 | [Contexto para seu assistente](produtos/setup/README.md) | SETUP | semente |
| FR-GRA-002 | [Escolha sua primeira automação](produtos/mapa/README.md) | MAPA | semente |
| FR-GRA-003 | [Confira a entrega da IA](produtos/teste/README.md) | TESTE | semente |
| FR-GRA-004 | [Desenhe agendamento no WhatsApp](produtos/agenda/README.md) | AGENDA | semente |
| FR-GRA-005 | [Prepare fontes para sua IA](produtos/pdf/README.md) | PDF | planejado |
| FR-GRA-006 | [Ferramentas de IA para tarefas reais](produtos/ferramentas/README.md) | FERRAMENTAS | planejado |

SKU identifica a oferta; versão identifica a entrega. Palavra-chave identifica a campanha e não substitui SKU. Semente é material produzido para teste; planejado tem somente escopo e não pode ser anunciado como entrega pronta.

## Uso e contribuição

Comece pelo README do produto. Exemplos são fictícios. Não adicione dados de clientes, credenciais, código proprietário ou snapshots de terceiros. Mudanças devem preservar autoria e incluir teste da entrega. Os materiais autorais estão sob CC BY 4.0; veja LICENSE.md.
